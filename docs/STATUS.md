## 已有实现

- Nuxt 多语言资讯与统计页面、预渲染、canonical、hreflang、结构化数据及 sitemap；演示站默认 noindex。
- Express / Prisma / MySQL 公开 API、单管理员会话、文章编辑与状态变更、媒体处理及 R2 存储。
- 管理端同源 BFF、HttpOnly Cookie、Origin / CSRF 保护及指定 CSRF 失效的一次恢复重试。
- 文章、审计及 BuildEvent 事务；worker 合并、派发和状态轮询；GitHub Actions 构建、SEO 审计及 Pages 部署。
- Pages Function 为客户端提供受限只读 API；图片组件处理加载先于水合的状态同步。
